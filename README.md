# AutoStudio — система онлайн-записи для автосервисов

Мультитенантное веб-приложение на React, TypeScript, Vite и FastAPI с базой данных SQLite.

**Возможности:**
- Отдельная публичная страница и кабинет владельца для каждой студии.
- Онлайн-запись с проверкой доступности времени и защитой от пересечения бронирований.
- Настройка услуг, цен, расписания, контактной информации и фотогалереи.
- Управление записями, платежами и возвратами.
- Клиентский и административный AI-помощники.
- PWA с адаптивным интерфейсом для мобильных устройств.
- Поддержка Docker и автоматической настройки HTTPS через Caddy.

**Технологии:** Python, FastAPI, React, TypeScript, Vite, SQLite, Docker.

**Запуск:** `run_local.bat`

**Локальные адреса:**
- Клиентская страница: `http://127.0.0.1:5173/s/sample/`
- Кабинет владельца: `http://127.0.0.1:5173/owner/sample/`
- API-документация: `http://127.0.0.1:8000/docs`

**Статус:** готовность к локальному запуску; публичное развёртывание требует настройки сервера и домена.
